# C - Singly Linked Lists

This project is about implementing and using singly linked lists in C. A singly linked list is a data structure where each node points to the next node in the list.

## what's in this project:

- `lists.h` - Header file with the structure and function prototypes
- `0-print_list.c` - Prints all elements of a list
- `1-list_len.c` - Returns the number of elements in the list
- `2-add_node.c` - Adds a node at the beginning
- `3-add_node_end.c` - Adds a node at the end
- `4-free_list.c` - Frees the entire list
